# Portfolio Website — Animesh Karki

I built this personal portfolio website as a project for my web development class. It demonstrates fundamental HTML and CSS concepts while applying principles of good web design, including visual hierarchy, consistent typography, intentional spacing, and accessible navigation.

## Objective
To create a clean, minimal portfolio that presents my academic background, professional experience, and personal projects in a straightforward, readable layout.

## Intent

This site is both a learning exercise and a functional showcase. I designed each section (About, Activity, Highlighted Work, Side Projects, Ideas) to practice structuring content with semantic HTML, styling with modular CSS, and making deliberate design choices around layout, color, and typography.


## What was covered

- HTML document structure and semantic elements (`<header>`, `<section>`, `<footer>`, `<nav>`)
- CSS selectors, the cascade, and specificity
- Flexbox for layout
- Relative and absolute positioning
- Typography pairing and `@font-face` declarations
- Responsive design via media queries

## Notes

This project intentionally keeps things simple. No frameworks, no build tools, just plain HTML, CSS, and a small amount of JavaScript (For the back-to-top button and media protection).
